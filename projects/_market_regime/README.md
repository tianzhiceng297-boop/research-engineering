# 市场状态项目

## 用途与调用边界
本项目为二级市场买点、交易时点与仓位评估提供环境约束。只有当具体投资研究进入这些决策阶段时，BOOT 才按需读取本项目；一级硬科技技术求真、产业链机制研究阶段不加载。

本项目维护两层市场状态：

## 1. 表层体征：可计算的市场数据
由 Python 脚本从明确的数据源计算，可能包括：
- 波动：指数/组合的实现波动、波动分位和波动变化；
- 宽度：上涨/下跌家数、站上指定均线的比例、创新高低数量等；
- 拥挤度：成交集中度、换手/融资指标、持仓或资金流代理指标等。

每个指标必须先定义数据源、覆盖市场/股票池、频率、窗口、单位、计算方法、脚本路径和缺失值处理。不同来源或口径不能直接拼接。未完成数据接入与脚本验证前，不填当前值。

## 2. 叙事层：定价机制与预期脆弱度
由问题图追踪：
- 当前市场主导的定价叙事及其传播载体；
- 价格对业绩、政策、利率、流动性等变量的反应函数；
- 叙事与基本面/政策/现金流变化之间的背离；
- 当前估值隐含的增长、利润率、融资和兑现条件；
- 哪些预期一旦落空，最容易造成定价重估。

叙事判断必须引用证据切片，注明观察区间、反例与置信程度，不能把媒体热度直接等同于市场共识。

## 数据时效与真实性约束
每个数据点或状态判断都要记录 `as_of`、source、脚本/公式、更新频率和 freshness_ttl（允许的最长有效期）。超过有效期标记为 stale；缺数据、脚本失败或无法复现标记为 unknown。不得把旧截图、旧行情或记忆中的市场状态当作当前事实。

**当前初始化状态：** 本项目仅建立数据与研究结构，尚未配置并验证自动数据管线，也未建立后台调度；因此没有可供调用的“当前市场状态”结论。

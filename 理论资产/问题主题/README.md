# 问题主题

本目录保存“问题”主题的理论研究资产。

## 定位

这部分内容**暂不并入正式的问题图系统 00–06 规约**。

它研究的不只是“问题图怎么画”，而是更基础的问题：

> **问题在人、研究和现实之间承担什么作用？**

当前已经形成一个工作假说：

> **问题可能是投资研究与沟通中跨场景复用的基本认知单元。**

因此，本主题开始覆盖：

- 问题的核心定义；
- 问题图的设计原则；
- 问题作为投资工作的认知单元；
- 澄清思考与问题形成；
- 人与AI的提问协作；
- 提问品味与AI问题沙盒；
- 问题与判断、投资判断资产之间的关系。

只有经过真实研究案例运行验证后，才决定其中哪些内容需要进入正式规约。

- `05_澄清思考与问题形成.md`：从模糊感觉到真正问题的形成过程
- `06_人机提问协作.md`：AI与人的提问分工与协作循环
- `07_提问品味与问题沙盒.md`：现实提问的认知表达，以及AI作为低成本问题试验场的作用
- `认知—问题图—研究—商业表达.md`：问题图、研究、认知模型与商业表达之间的关系

## 当前核心链条

```
模糊感觉 / 异常 / 好奇 / 目标
          ↓
      澄清思考
          ↓
       真正的问题
          ↓
        问题图
          ↓
       研究与验证
          ↓
          判断
          ↓
     行动 / 沟通 / 交付
          ↓
       新问题
```

AI可以在整个过程中承担问题扩展、反问、反例生成、追问和整理等工作；人保留对问题重要性、现实提问和最终判断的控制。

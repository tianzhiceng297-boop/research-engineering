# 问题主题

本目录保存“问题”主题的理论研究资产。

## 定位

这部分内容**暂不并入正式的问题图系统 00–06 规约**。

它研究的不只是“问题图怎么画”，而是更基础的问题：

> **问题在人、研究和现实之间承担什么作用？**

当前已经形成一个工作假说：

> **问题可能是投资研究与沟通中跨场景复用的基本认知单元。**

因此，本主题开始覆盖：

- 问题的核心定义；
- 问题图的设计原则；
- 问题作为投资工作的认知单元；
- 澄清思考与问题形成；
- 人与AI的提问协作；
- 提问品味与AI问题沙盒；
- 问题与判断、投资判断资产之间的关系；
- 以还原商业现实为目标，研究商业主体、交易、利益分配和演化机制。

只有经过真实研究案例运行验证后，才决定其中哪些内容需要进入正式规约。

## 当前核心链条

```
模糊感觉 / 异常 / 好奇 / 目标
          ↓
      澄清思考
          ↓
       真正的问题
          ↓
        问题图
          ↓
       研究与验证
          ↓
          判断
          ↓
     行动 / 沟通 / 交付
          ↓
       新问题
```

AI可以在整个过程中承担问题扩展、反问、反例生成、追问和整理等工作；人保留对问题重要性、现实提问和最终判断的控制。

## 商业现实还原：新增理论方向

新增的工作假说是：问题图的顶层目标可以设为**还原与研究决策相关的商业现实**。研究不只整理行业信息和产业链环节，还要解释商业主体如何在权力、资源和制度约束下发生交易、创造价值、分配利益、承担风险并持续演化。

产业研究需要追踪四条相互连接的链：价值创造、价值获取、现金兑现和资本兑现。具体定位、对象边界、验收标准与待验证事项见：

`08_问题图的目标_还原商业现实.md`

该定位仍属于理论资产，不改变正式问题图系统 00–06 规约。商业现实是研究对象，问题图是组织认知缺口的研究结构，商业现实模型是基于证据形成的阶段性理解，三者不可混为一谈。

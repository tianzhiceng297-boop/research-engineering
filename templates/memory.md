# Research Memory

本文件不重复记录 graph.yaml 中的当前问题、claim、答案或证据。它只保存负知识、等待机会雷达，以及跨轮容易误用的机制/概念边界。

## 1. 逻辑证伪与停枝黑名单（Pass / Pruned）

| 被剪枝对象/方向 | 剪枝死穴（具体证据/机制） | 适用边界 | 重开触发条件（Watchlist Trigger） | 记录日期 |
|---|---|---|---|---|
|  |  |  |  |  |

不要只写“不要研究”。必须说明当时为什么停止、证据适用范围，以及什么变化会使旧结论失效。历史判断不是永久结论。

## 2. 好资产高赔率等待雷达（Watchlist）

| 标的/方向 | 核心看点 | 当前为何不行动（估值透支/缺现金流/卡点/时点） | 等待触发器与重新评估条件 |
|---|---|---|---|
|  |  |  |  |

等待雷达是研究记忆，不代表已经建立自动行情监控。若要持续监测，必须另有可运行的数据源、脚本与调度，并记录最近更新时间。

# 研究工程

这是曾天智的研究生产系统仓库。

它不用于堆放所有历史材料，也不试图一次性写完一套宏大的方法论。当前任务是把已经形成的研究资产放进真实项目中使用，记录哪些东西有效、哪些缺失、哪些需要修改，再逐步沉淀为可重复调用的动作、流程和能力。

## 当前阶段

**资产重整后的运行验证。**

第一条验收线路使用 CQD 短波红外研究项目，检查以下过程能否完整运行：

```
材料进入 → 问题展开 → 形成判断 → 制作交付 → 检查修订 → 版本归档
```

## 仓库中的对象

- **资产**：可复用的材料、模板、规范和方法。
- **动作**：在特定条件下对输入执行的一项明确操作。
- **流程**：按依赖关系连接起来的一组动作。
- **项目**：用真实问题检验资产、动作和流程的工作现场。
- **交付**：面向具体使用者形成的正式成果。
- **记录**：对修改原因、验证结果和未解决问题的追踪。

## 当前原则

1. 先运行，再补结构。
2. 只有被真实任务调用过的内容，才进入正式资产。
3. 研究结论、证据、推断和未知项分开记录。
4. 修改保留原因和历史，不用覆盖旧文件来假装问题从未发生。
5. 首次交付形成完整研究包；后续更新以增量为主，结构发生明显变化时再发布新的完整版本。

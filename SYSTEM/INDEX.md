# SYSTEM 索引

日常冷启动默认不批量读取 `00-06/` 或 `THEORY/`。先按根目录 `BOOT.md` 执行；遇到具体方法疑难时再查阅本索引。

| 遇到的问题 | 按需读取 |
|---|---|
| 为什么这样设计、人机边界争议 | `00-06/01_核心设计原则.md` |
| 节点、边、桥问题的语义定义 | `00-06/02_问题图本体.md` |
| 复杂状态、反证、停枝与重新打开动作 | `00-06/03_Agent问题研究执行协议.md` |

| 研究结果如何压缩为商业交付 | `00-06/06_问题图与研究交付接口.md` |

`00-06/00_系统总说明.md` 是正式规约总说明；当需要理解整套规约组成或读取路由时查阅。

`THEORY/` 保存尚未升级为正式规约的理论资产。正常行业研究不主动加载；只有讨论系统设计、理论假设或正式规约无法解决的方法问题时，才按主题读取。

项目运行态以各项目目录中的 `graph.yaml` 为准；历史负知识按项目模板维护。不要把项目经验自动升级为通用规则。
